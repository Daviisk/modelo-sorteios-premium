# Modelo Sorteios Premium

Demonstração neutra para apresentação comercial. **Não processa pagamentos reais e não realiza sorteios reais.** O fluxo de números, resumo e checkout são demonstrativos, sem banco de dados.

Para operar comercialmente: configurar banco de dados isolado por cliente, autenticação, painel administrativo, integração Mercado Pago, webhooks, controles de disponibilidade, auditoria e regulamento aplicável. Nunca reutilizar credenciais ou dados de clientes do projeto original.
